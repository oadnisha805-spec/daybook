What Daybook does

Everything a daily to-do list needs, and nothing that gets in the way.

Add and edit in one place

Type a name, pick a category and a due date, press Add. Double-click any task to edit it where it sits.

Categories

Sort tasks into Work, Personal, Study or Other. Each category chip shows how many tasks it holds.

Filters and search

Switch between All, Active and Completed, narrow by category, and search by words in the task name.

Drag to reorder

Grab the handle with a mouse or finger. Keyboard users can move a task with the arrow keys.

Overdue flag

A task past its due date is marked in red until you complete it.

Saved automatically

Every change is written to the browser, so your list is still there after a reload. Deleted something by mistake? Undo it.

How it works

Three moves cover the whole day.

  1. Add a task

    Write what needs doing, choose a category, and set a due date if there is one.

  2. Organise the list

    Drag tasks into the order you plan to do them. Filter or search when the list grows.

  3. Tick it off

    Tap the checkbox. The task is struck through and the progress bar at the top moves up.

Built with

A front-end project with plain web technology.

  • JavaScript (ES6+)
  • DOM manipulation
  • localStorage API
  • CSS transitions
  • Responsive CSS

No frameworks and no server dependencies. The whole site is static files.
